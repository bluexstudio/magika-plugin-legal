# FlagScope Privacy Notice

Effective date: September 16, 2026

FlagScope analyzes supported files in the currently open local project. It does
not collect, transmit, sell, or store source code, usage analytics, telemetry,
personal data, credentials, or feature-flag values outside the local IDE
process. It makes no network requests.

If a later release changes this behavior, the implementation, this notice, and
the Marketplace description will be updated together before publication.
